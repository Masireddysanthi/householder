# 🏠 House Price Predictor

A simple machine learning project that predicts house prices based on features like the number of bedrooms, bathrooms, square footage, and lot size using **Linear Regression**.

## 🔍 Features Used
- `bedrooms`: Number of bedrooms
- `bathrooms`: Number of bathrooms
- `sqft_living`: Living area in square feet
- `sqft_lot`: Lot size in square feet

## 📊 Technologies
- Python
- Pandas
- Scikit-learn

## 🚀 How It Works
1. A small sample dataset is created using pandas.
2. The model uses selected features to predict house prices.
3. Data is split into training and testing sets.
4. A `LinearRegression` model is trained on the training set.
5. The model predicts prices and evaluates performance using Mean Squared Error (MSE).
6. You can also try predicting the price of a custom house.
